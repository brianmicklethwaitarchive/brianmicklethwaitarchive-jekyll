This is the web site for The Brian Micklethwait Archive.

It uses the Jekyll static web site generator.

# Rules
The website is currently maintained by one person, so use "I" when referring to him.

# Files and Directories
The la subdirectory contains markdown versions of Libertarian Alliance pamphlets
written by Brian that have been converted from PDF to markdown format.

When making any substantial changes to the site, it is usual to add a post in
the news subdirectory.

The file quotes.yml is used by the generate_quotes.py script to produce code that
is included in index.markdown.
